## Keeping it true

These pages describe what the app **actually does**, which is the only thing that makes them
worth publishing. If any of the following changes in the app, the pages must change with it:

- the Umeng SDKs (U-App / U-APM) being added, removed, or reconfigured
- an analytics opt-out being added — the policy currently states plainly that there is none
- anything new that leaves the device
- the subscription price or trial length

Update the "last updated" date at the top of every page you touch.
